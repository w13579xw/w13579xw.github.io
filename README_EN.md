# Junxiang Wang (@w13579xw) · Personal Portfolio

Live Site: [https://w13579xw.github.io](https://w13579xw.github.io)

A zero-dependency, modern tech-styled personal portfolio built with vanilla `HTML / CSS / ES Module JS` (inspired by Linear & Vercel), featuring:

- 🌗 **Dark / Light Theme Toggle** with preference persistence
- 🌐 **Instant Chinese / English Switching** powered by structured `data.js`
- 🔍 **Interactive Project Category Filters** (All / Agent & LLM / Embodied AI / Research)
- ⌨️ **Command Palette** (`Ctrl + K` / `⌘ + K`) for quick navigation and actions
- 🚀 **Native GitHub Pages Deployment** directly from `main`

## Local Preview

```bash
python -m http.server 8080
# Visit http://localhost:8080
```
